# 🏥 Cedar-Valley-Health-Identity-Modernization
Microsoft Entra ID IAM project demonstrating Zero Trust, RBAC, bulk user provisioning, MFA, and cloud identity administration through a fictional healthcare organization.


## Enterprise Identity & Access Management Portfolio Project

This repository documents the identity modernization journey of Cedar Valley Health, a fictional healthcare organization implementing Microsoft Entra ID and Zero Trust security practices.

The project demonstrates how an organization can mature its identity environment through user lifecycle management, access control, authentication security, governance, and automation.
